# 📦 Grocery Inventory Management System

A database driven inventory management system built for small and medium sized grocery stores. It replaces error prone manual methods like notebooks and spreadsheets with a centralized system that tracks stock levels, monitors expiry dates, and automates routine inventory tasks.

---

## 🧩 Problem

Many small and medium-sized grocery stores rely on manual methods to manage inventory. These approaches lead to:

- **Inaccurate stock levels** — manual entry errors cause mismatches between records and actual stock
- **Unexpected shortages & overstock** — no reliable system to trigger restocking or flag excess inventory
- **Untracked expiry dates** — expired products go unnoticed, resulting in waste and health risks
- **Poor decision-making** — unreliable data undermines daily operations and customer satisfaction

---

## ✅ Solution

This system provides a centralized, database-backed platform that:

- Maintains accurate, real-time inventory records
- Alerts staff to low stock and expiring items
- Reduces manual data entry and human error
- Supports better operational decisions with reliable data
